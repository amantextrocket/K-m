# 🔴 Kabir Mobile — Second Hand Smartphone Store

Welcome to the official repository for **Kabir Mobile**.

## 📱 Features Included
- **Customer Side**: Premium Red & White UI, Brand Filtering, Instant Mobile Search, Cart System, Direct WhatsApp Cash-on-Delivery Checkout.
- **Admin Panel**: Manage Inventory, Add Mobile with details (Battery Health, Condition, Storage), Delete items directly from iPhone/Mobile.

## 📁 File Structure
- `index.html`: Main Customer Storefront.
- `admin.html`: Store Manager / iPhone Admin Panel.
- `style.css`: Red & White responsive styling.
- `app.js`: Cart logic, Search, Filters, and Firebase Integration engine.
- `README.md`: Project Documentation.
